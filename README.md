
### MM Canvas Export for [Obsidian](https://obsidian.md/)

A simple and lightweight plugin that allows to export any canvas (even very complex and large ones!) as an image file. This is something the popular plugin *Advanced Canvas* has trouble doing, but is no issue at all for this tool right here :)

---
#### Features
- Image size export between 2,000px and 20,000px supported
- Custom padding for extra margins
- Themes also supported
- For attachments and links, file names and paths can be hidden or not

#### Installation

Community plugins
1. In Obsidian, open *Settings > Community plugins*
2. Make sure **Restricted mode** is turned off (click **Turn on community plugins** if needed)
3. Click **Browse**, search for **MM Canvas Export**, and open its page
4. Click **Install**, then **Enable**
5. You can now use the export function from the left ribbon icons or by right-clicking on the canvas in the navigation pane.

Github / Ko-Fi Shop
1. Download the latest release of *MM Canvas Export*
2. Extract its content into your Obsidian vault folder, under */.obsidian/plugins/mm-canvas-export/*
3. In Obsidian, make sure to turn on the plugin in *Settings > Community plugins*
